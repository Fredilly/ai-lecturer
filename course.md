<div class="card" style="border-left:5px solid #6a1b9a;">
  <h2>JISU Specialist Offering: AI for Language, Communication & Culture</h2>
  <p>This course is designed to connect applied AI with a university environment centered on languages, international communication and cross-cultural education.</p>
  <ul>
    <li>Natural language processing and multilingual text analysis</li>
    <li>Machine translation and translation-quality evaluation</li>
    <li>Sentiment, discourse and content analysis</li>
    <li>Generative AI and large language models in language learning</li>
    <li>Evaluating hallucination, bias and reliability across languages</li>
    <li>Responsible AI use in education, writing and assessment</li>
  </ul>
  <p><strong>Student outcome:</strong> students complete a small multilingual AI project and present both the technical method and the cultural/communication implications of the result.</p>
</div>

<div class="card">
  <h2>Learning Outcomes / 学习成果</h2>
  <p>By the end of the semester, students should be able to:</p>
  <ul>
    <li>Explain the main ideas behind machine learning, deep learning, NLP and computer vision.</li>
    <li>Use Python, NumPy and Pandas to prepare, inspect and analyze data.</li>
    <li>Build and evaluate regression, classification and clustering models with Scikit-learn.</li>
    <li>Construct reproducible ML pipelines with preprocessing and feature engineering.</li>
    <li>Apply introductory NLP methods to text classification and sentiment tasks.</li>
    <li>Read data from files, APIs and databases and validate data quality.</li>
    <li>Use Git, testing and documentation to support reproducible technical work.</li>
    <li>Design, implement, evaluate and present an end-to-end AI project.</li>
  </ul>
</div>

<h2 style="text-align:center; font-size:1.8rem;">16-Week Semester Plan / 16周课程大纲</h2>

<div class="card"><h3>Weeks 1–2 · Python & AI Programming Foundations</h3><p>Python review, Jupyter/VS Code setup, virtual environments, functions, comprehensions, generators, core OOP and reproducible project structure.</p><p><strong>Lab:</strong> set up a reproducible Python environment and build a small data-processing program.</p></div>

<div class="card"><h3>Weeks 3–4 · Numerical Computing & Data Manipulation</h3><p>NumPy arrays, vectorization, linear algebra, Pandas Series/DataFrames, filtering, grouping, joins, reshaping, dates and missing values.</p><p><strong>Lab:</strong> clean and analyze a real CSV dataset and produce a concise analytical report.</p></div>

<div class="card"><h3>Weeks 5–6 · Data Quality, APIs, Databases & Visualization</h3><p>Data validation, duplicates, outliers, schema checks, CSV/JSON/Excel, REST APIs, SQLite, Matplotlib and explanatory visualization.</p><p><strong>Lab:</strong> API → JSON → Pandas → validation → SQLite → visualization pipeline.</p></div>

<div class="card"><h3>Weeks 7–8 · Machine Learning Foundations</h3><p>Supervised vs. unsupervised learning, train/test splits, overfitting, cross-validation, baseline models and the Scikit-learn estimator API.</p><p><strong>Lab:</strong> build a complete preprocessing and classification pipeline and diagnose overfitting.</p></div>

<div class="card"><h3>Weeks 9–10 · Regression, Classification & Model Evaluation</h3><p>Linear/logistic regression, tree-based models, k-nearest neighbors, confusion matrices, precision/recall/F1, ROC-AUC and error analysis.</p><p><strong>Lab:</strong> compare several models and defend a model choice using appropriate metrics.</p></div>

<div class="card"><h3>Weeks 11–12 · Unsupervised Learning & Introductory NLP</h3><p>Clustering, dimensionality reduction, text preprocessing, bag-of-words/TF-IDF, text classification and sentiment analysis.</p><p><strong>Lab:</strong> build and evaluate a simple text classifier using a documented reproducible workflow.</p></div>

<div class="card"><h3>Week 13 · Neural Networks & Computer Vision Concepts</h3><p>Conceptual introduction to neural networks, training loops, embeddings, convolutional networks and practical limits of deep learning.</p><p><strong>Lab:</strong> guided introductory experiment using a small neural-network or image-classification example.</p></div>

<div class="card"><h3>Week 14 · Generative AI, LLMs & Responsible Use</h3><p>How modern language models are used, prompt design, evaluation, hallucination, bias, privacy, academic integrity and responsible deployment.</p><p><strong>Lab:</strong> compare model outputs against a small evaluation rubric and document failure modes.</p></div>

<div class="card"><h3>Week 15 · Capstone Development & Research Practice</h3><p>Problem definition, literature search, hypothesis formation, experiment design, baseline selection, reproducibility and interpretation.</p><p><strong>Lab:</strong> capstone clinic with code review, experiment review and presentation rehearsal.</p></div>

<div class="card"><h3>Week 16 · Final Project Presentations</h3><p>Students present their problem, dataset, method, evaluation, limitations and next steps. Assessment emphasizes reasoning and evidence, not only model accuracy.</p></div>
